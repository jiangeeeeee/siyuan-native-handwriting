# 源生笔迹 0.14.5 同步文件存储更新报告

## 备份逻辑：之前 → 现在

之前，每批笔迹保存都会新建日志文件；启动、退出和定时备份也会另存一份全量 JSON。文件缺少合并和去重，使用时间越长，同步文件越多。

现在，同一文档或白板在同一设备上更新固定的数据文件。自动备份只处理有变化的文档，轮换保留当前版和上一版。空文档、内容未变或反复启停，都不再新增重复备份。

## 减少了多少文件

本次整理本机工作空间的结果如下，统计范围为插件的笔迹数据和备份文件。

| 项目 | 整理前 | 整理后 |
| --- | ---: | ---: |
| 笔迹数据文件 | 1,486 | 33 |
| 备份文件 | 244 | 66 |
| 合计 | 1,730 | 99 |
| 占用空间 | 2.36 GiB | 56.36 MiB |

共减少 1,631 个文件，约 94.28%；占用空间减少约 97.66%。66 个备份文件包括 33 个历史汇总和 33 个当前备份。

## 怎么实现

保存时，以文档／白板和设备标识生成固定文件名，合并同一笔迹的最新操作，保留删除记录和图层状态。不同设备各自写入，再合并数据。

旧日志按文档汇总，历史备份按操作记录去重。合并文件写入后会重新读取并校验，确认内容一致才移除旧文件。整理入口位于「三个点 → 备份与恢复 → 整理同步文件」。

## 测试结果

已完成现有全部功能用例回归，53 项单元测试、104 项浏览器测试均通过，覆盖书写、橡皮、圈选、白板、图层、导出、授权、工具栏及备份恢复。

整理前后，33 份文档／白板、1,830 条可见笔迹一致；4,801 条历史操作及 155 个非空历史状态完整保留。连续保存 200 次复用同一数据文件，备份变化 30 次仅轮换当前版和上一版。本机安装 0.14.5 后反复启停 3 轮，文件数量、路径与内容均未变化。
